Работа с удалёнными репозиториями в Git:

1. git clone — создаёт локальную копию удалённого репозитория.
2. git push — отправляет локальные изменения в удалённый репозиторий.
3. git pull — получает изменения из удалённого репозитория.
4. git fetch — получает изменения без слияния.
5. Конфликты возникают при изменении одних и тех же строк в разных версиях.
